How this works: this page parses the EDF/BDF binary format directly in your browser tab — the file is read with the File API and never uploaded anywhere. Physical-unit values are computed from each channel's own digital/physical scaling exactly as the file specifies.

Multi-channel export: channels selected together for one CSV must share the same sample rate (EDF/BDF files often mix rates, e.g. a fast EEG channel alongside a slow temperature channel). Select channels with matching rates, or export one group at a time.

Large files: a long, high-rate recording can produce a very large CSV. Narrow the time range first if you only need part of the recording.

Troubleshooting

The export button stays disabled after I select channels

Channels selected together for one CSV export must share the same sample rate. EDF/BDF recordings often mix a fast signal (like EEG at 256 Hz) with a slow one (like a temperature channel at 1 Hz) — select channels with matching rates, or export each group separately.

Excel won't open my exported CSV cleanly, or it takes forever

A long, high-sample-rate recording can produce a CSV with more rows than a spreadsheet can comfortably handle (Excel's own row limit is 1,048,576). Narrow the time range before exporting if you only need part of the recording.
